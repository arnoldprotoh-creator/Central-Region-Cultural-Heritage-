NGWAO BOTSWANA — WEBSITE PACKAGE
================================

CONTENTS
- index.html       Home page
- heritage.html    Central District heritage: Old Palapye, Lecheng Pan, Moremi Gorge, Khama Rhino Sanctuary
- people.html      Communities, pottery, leadership and traditions
- beyond.html      Selected heritage places around Botswana
- sources.html     Research references and image credits
- assets/css/style.css  Shared responsive brown-and-green design
- assets/js/site.js     Responsive navigation and active-page state
- assets/images/ngwao-logo.svg  Original static vector logo (not animated)
- PROJECT-REPORT.txt    Project summary and submission checklist

HOW TO OPEN
1. Extract the ZIP folder fully.
2. Open the botswana_heritage_website folder.
3. Double-click index.html in a modern browser.
4. Keep an internet connection available for the linked photographic images.

IMPORTANT IMAGE NOTE
The site currently references photographs hosted on Wikimedia Commons using direct file URLs. The image files themselves are not embedded locally in this ZIP because external image downloads were unavailable during package creation. Therefore, the photos require an internet connection. The original static logo and all HTML/CSS/JavaScript files are included locally. The Old Palapye photograph is explicitly included on the home page and Central Heritage page via its Wikimedia Commons source.

For an offline-ready submission, obtain and save the original image files with the relevant reuse permissions, place them in assets/images, then change each image src to its local filename. Do not present the regional Tswapong–Lotsane satellite image as a verified close-up of Lecheng Pan. Add a community-verified Lecheng Pan photograph if you can obtain one with permission.

DESIGN
Earthy brown, forest green, warm cream and muted gold palette; editorial typography; clear sticky navigation; mobile menu; photo-led cards; responsive layouts; captions and source page.
